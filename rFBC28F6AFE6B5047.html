struct RobotDriver

Declaration

struct RobotDriver { /* full declaration omitted */ };

Description

Interface a robot driver plugin implements to connect a robot to URI. `uri interface` calls sync() once per cycle, then reads the state with the getters and sends the latest command with servoJ(), speedJ() or tauJ(), depending on the robot's `controller.mode`. Joint vectors follow the RobotModule's reference joint order. See docs/NewRobotDriver.md.
