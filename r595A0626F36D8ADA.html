class Controller

Declaration

class Controller { /* full declaration omitted */ };

Description

Control framework run by `uri manager`, loaded as a backend plugin. Implement it to support a controller other than mc_rtc (see docs/RobotManager.md, "Controller backend"). Robots are identified by their name under `Robots:`, and joint vectors follow each robot's reference joint order.
